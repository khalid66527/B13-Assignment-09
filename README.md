# 🚗 CarPark - Modern Car Rental Platform

Welcome to **CarPark**, a premium and responsive car rental web application designed to connect car owners with renters seamlessly. Whether you want to list your car for renting or find a perfect ride for your next trip, CarPark provides a hassle-free, secure, and user-friendly experience.

## ✨ Key Features

Here are some of the main features that make **CarPark** stand out:

*   **🔒 Secure Authentication (Better Auth):** Implements robust and secure credentials-based sign-in/sign-up alongside seamless Google OAuth integration, ensuring user data privacy and account safety.
*   **🚗 Comprehensive Car Management:** Logged-in users can list their cars for rent, view detailed lists of their added cars, edit car details dynamically using beautiful modals, and delete listings if they are no longer available.
*   **🔍 Advanced Search & Filter System:** Easily find the perfect car by filtering by model, brand, location, or availability status. Users can search for specific cars in real-time.
*   **📅 Seamless Booking & Cancelation Workflow:** Renters can book their favorite cars with simple clicks. They can also manage all active bookings from their personal dashboard and cancel bookings if their plans change.
*   **📊 User Dashboard & Statistics:** A dedicated space for users to manage their listings, monitor active bookings, update their profile settings, and check booking statistics in real-time.
*   **🎨 Premium Responsive UI/UX:** Built with TailwindCSS v4, DaisyUI, and HeroUI (NextUI) featuring dark/light integrations, modern glassmorphic headers, responsive mobile navigation, and beautiful interactive feedback via toast notifications.

## 🛠️ Tech Stack

### Frontend & Core
*   **Next.js (v16.2)** - React framework for production-grade app structures, server components, and routing.
*   **React (v19.2)** - Core UI rendering library.
*   **TailwindCSS (v4.0)** - Modern utility-first CSS styling framework.
*   **DaisyUI & HeroUI (v3.0)** - Beautiful component libraries for clean, interactive, and responsive user interfaces.

### Authentication & Database
*   **Better Auth (v1.6)** - Next-generation authentication library.
*   **MongoDB & `@better-auth/mongo-adapter`** - Database and integration adapter for secure session storage and data persistence.

### Utilities
*   **React Toastify & React Hot Toast** - For elegant, interactive success and error notifications.
*   **React Icons & Lucide React** - High-quality, modern, and light icons.
